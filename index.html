Parte 1: El tren de tareas (lista enlazada)

Una lista enlazada es un tren: cada vagón (nodo) guarda un dato y la dirección del vagón siguiente. Ningún vagón está adentro de otro; están sueltos y conectados por flechas.

Ejemplo 1: la hoja de ruta de un proyecto

python
# El molde para fabricar vagones
class Nodo:
    def __init__(self, tarea):
        self.tarea = tarea        # lo que lleva este vagón
        self.siguiente = None     # todavía no está enganchado a nadie

# Fabrico tres vagones sueltos
t1 = Nodo("Armar el circuito en protoboard")
t2 = Nodo("Programar el sensor de nivel")
t3 = Nodo("Hacer la web del proyecto")

# Los engancho: t1 -> t2 -> t3 -> None
t1.siguiente = t2
t2.siguiente = t3

# El cartero recorre el tren desde la locomotora
def mostrar(cabeza):
    actual = cabeza
    numero = 1
    while actual is not None:
        print(numero, "-", actual.tarea)
        actual = actual.siguiente
        numero += 1

mostrar(t1)

Ejemplo 2: agregar una tarea urgente adelante

python
def agregar_al_inicio(cabeza, tarea):
    nuevo = Nodo(tarea)       # fabrico el vagón nuevo
    nuevo.siguiente = cabeza  # lo engancho delante de la locomotora
    return nuevo              # ¡ahora él es la cabeza!

t1 = agregar_al_inicio(t1, "Comprar el sensor que falta")
mostrar(t1)
Ojo con el detalle: si te olvidás de guardar lo que devuelve la función (t1 = ...), la tarea nueva se pierde.

Parte 2: El mapa de stands (árbol binario de búsqueda)

Un árbol binario de búsqueda es un mapa con bifurcaciones: en cada cruce, si lo que buscás es menor vas a la izquierda y si es mayor vas a la derecha. En cada paso descartás la mitad del camino.

Ejemplo 3: cargar los stands de la Expo

Los stands llegan en este orden: 14, 8, 22, 3, 11, 18, 27. Así queda el árbol:

              [14]
            /      \
         [8]        [22]
        /   \      /    \
      [3]  [11]  [18]   [27]
python
# El molde para fabricar cruces del mapa
class NodoArbol:
    def __init__(self, stand, proyecto):
        self.stand = stand          # número de stand (la "llave")
        self.proyecto = proyecto    # nombre del proyecto
        self.izq = None             # camino de los menores
        self.der = None             # camino de los mayores

def insertar(raiz, stand, proyecto):
    if raiz is None:                        # lugar vacío: me ubico acá
        return NodoArbol(stand, proyecto)
    if stand < raiz.stand:                  # menor: voy a la izquierda
        raiz.izq = insertar(raiz.izq, stand, proyecto)
    else:                                   # mayor: voy a la derecha
        raiz.der = insertar(raiz.der, stand, proyecto)
    return raiz

Ejemplo 4: buscar un stand contando pasos

python
def buscar(raiz, stand):
    actual = raiz
    pasos = 0
    while actual is not None:
        pasos += 1
        print("Visito el stand", actual.stand)
        if stand == actual.stand:
            print("¡Encontrado en", pasos, "pasos!")
            return actual.proyecto
        elif stand < actual.stand:
            actual = actual.izq
        else:
            actual = actual.der
    print("No existe ese stand")
    return None
